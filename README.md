## Features

- Admin Portal
- Employee Portal 
- Authentication and Authorization
- Create New Employee
- Generate QR Code
- Scan QR Code 
- Visualize the Data on Different Charts
- Interconnection between Employee and Admin Portal 


## Tech Stack

**Client:** React, Redux, TailwindCSS, Antd

**Server:** Node, Express

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

Backend
```bash
DATABASE_URL ="mongodb://127.0.0.1:27017/myapp" 
JWT_SECRET_KEY = "secret"
PORT= 5000
```
Frontend
```bash
REACT_APP_backend_url=  https://kishore-jeevan-fyp-api.vercel.app/api
PORT = 3000
```

## Run Locally

Clone the project

```bash

```

Go to the project directory

```bash

```

```bash
  cd FYP/frontend
  and 
  cd FYP/backend 
```
Install dependencies
```bash
  npm install -f 
```
 Run The Servers 
```bash
  
  Frontend
  npm run start
  backend
  npm run dev
```
